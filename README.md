## 🌟 Overview

**Meta-AI Web Builder** is a zero-cost, API-key-free application architect and code generator. It bridges user requests with free web-based LLMs (**Gemini Web**, **DeepSeek Web**, **Claude Web**, and **ChatGPT Web**) to build, preview, export, and sync production-grade web and mobile applications without incurring paid API token charges.

### Why Meta-AI Web Builder?
- **Zero API Costs**: No need for expensive OpenAI, Anthropic, or Gemini API keys.
- **Multi-Model Intelligence**: Leverages the unique strengths of specialized web AI models across distinct pipeline stages.
- **In-Browser Sandbox**: Instant preview using an in-browser Babel transformer and sandboxed iframe.
- **Native Binary Suite**: Automated cross-platform packaging for Windows (`.exe`), macOS (`.dmg`), Linux (`.AppImage`), and Android (`.apk`).
- **Cloud Auto-Sync**: Direct integration with Google Drive REST API v3 to auto-sync generated source trees.

## ✨ Key Features

- 🧠 **5-Stage Pipeline Wizard**: Seamless step-by-step workflow from idea prompt to final synced repository.

## 🔌 Chrome Extension Auto-Bridge (Zero-API)

Meta-AI Web Builder includes an embedded Manifest V3 Chrome Extension generator. The extension monitors web AI chat windows (Gemini, DeepSeek, Claude, ChatGPT) and automatically transfers generated outputs into Meta-AI Builder without manual copy-pasting.

### Quick Setup:
1. Open Meta-AI Web Builder and click **Auto-Bridge** in the top navigation.
2. Click **Download Chrome Extension (.zip)** and unpack the archive.
3. Open Chrome and navigate to `chrome://extensions`.
4. Enable **Developer mode** (top-right toggle).
5. Click **Load unpacked** and select the unzipped directory.
6. Open your favorite web AI—responses will automatically sync!

## ☁️ Google Drive REST API Auto-Sync

Directly backup and share generated projects:
1. Obtain a Google OAuth Access Token with `https://www.googleapis.com/auth/drive.file` scope.
2. Enter the token in **Stage 5: Google Drive Auto-Sync**.
3. Click **Start Sync**—Meta-AI Web Builder recursively creates project folders and uploads all source files.
4. Auto-shares ownership/edit rights with designated accounts (e.g. `athanu000@gmail.com`).

## 🚀 Quick Start & Installation

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/meta-ai-web-builder.git

# Navigate into directory
cd meta-ai-web-builder

# Install dependencies
npm install

# Start development server
npm run dev
```

App will be available at `http://localhost:3000`.
